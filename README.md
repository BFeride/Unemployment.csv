# Unemployment Analysis in India - CodeAlpha Task 2

This project is part of my Python Programming Internship at CodeAlpha. It focuses on analyzing economic indicators and visualizing unemployment rates using Python.

1.Project Overview
The goal of this task is to perform Exploratory Data Analysis (EDA) on the "Unemployment in India" dataset. The workflow includes data cleaning, correlation analysis, distribution tracking, and time series trend analysis.

2.Libraries Used
- **Pandas** (Data manipulation and cleaning)
- **NumPy** (Numerical operations)
- **Matplotlib & Seaborn** (Data visualization)

3.Steps Performed
1. **Data Cleaning:** Stripped whitespace from column names, checked for null values, and dropped missing data.
2. **Correlation Matrix:** Generated a heatmap to analyze the correlation between numerical variables.
3. **Distribution Analysis:** Plotted a histogram with KDE to see the spread of the estimated unemployment rate.
4. **Time Series Analysis:** Converted date formats to extract years and plotted the average yearly unemployment trend using a line plot.
